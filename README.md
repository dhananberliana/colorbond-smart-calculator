# Material Calculator

Development scaffold for a roofing and wall cladding estimator. All profile data must be verified before production use.

## Local development

Install Node.js 22, then run `npm install` and `npm run dev`. Open http://localhost:3000.

## Roadmap
- Responsive calculator UI
- Per-plane material estimation and verified profile catalogue
- Database, authentication, admin and Google integration

No credentials or customer data should be committed.
